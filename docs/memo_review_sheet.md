# 备忘录盲审表（10 份，约 2 小时）

评审前只看备忘录，不看系统配置、不看对话轨迹。两人独立打分，再对分歧。

## 每份记录

| 字段 | 内容 |
|---|---|
| 编号 | M01–M10 |
| 案由 | 劳动 / 侵权 |
| 评审人 | A / B |

## 五项 0/1

| # | 维度 | 通过标准 | 得分 |
|---|---|---|---|
| 1 | 结论可追溯 | 每条结论都能指到具体法条或计算式 | 0 / 1 |
| 2 | 事实与假设分离 | 明确区分当事人陈述、材料支持、系统假设 | 0 / 1 |
| 3 | 缺口诚实 | 未编造缺失事实；给出补材清单 | 0 / 1 |
| 4 | 时效与版本 | 适用版本与案发日一致；时效结论明确 | 0 / 1 |
| 5 | 可读性 | 非法律人士能看懂结论与下一步 | 0 / 1 |

## 错误类型（可多选）

- [ ] 引错法条 / 引了不存在的条文
- [ ] 适用了案发日尚未生效的版本
- [ ] 金额算错或漏算封顶/代通知金
- [ ] 把当事人陈述当成已证明事实
- [ ] 漏掉关键抗辩（时效、程序、举证责任）
- [ ] 过度结论（把“可能”写成“一定”）
- [ ] 其他：______
