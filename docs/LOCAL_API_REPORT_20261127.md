## 根据真实失败做的本地修复

- 分诊识别孕期、生育保护、主动辞职，避免把到期不续签中的“劳动合同”误加为另一条请求权。
- 已标记字段的回答与更正延续当前咨询，修复工伤伤残等级更正被切换为交通侵权的问题；明确新增问题仍可分诊。
- 抽取保留当前话语明确给出的文本期间，限制到当前请求权声明的字段，并将只出现在 `corrections` 中的新值纳入更新。
- 补齐已声明关键字段到追问路径的连接，关键证据字段也可追问；保留问题预算及原有条件分支。
- 程序类的仲裁日期、仲裁进展、起诉状态和时效认知不能因金额情景不变而被VOI提前跳过。
- 为本地DeepSeek配置 `LLM_THINKING=disabled`，防止思考消耗短输出上限；空正文按失败记录，保留tokens及结束原因。
- 评测支持可选 `--workers`，默认仍为1。实际本轮使用8个独立会话并发；顺序、内存数据库隔离及评分一致性有回归检查。

本次对比同时包含产品修复与模型思考配置变化，不能把全部提升单独归因于某一项改动。

中间一轮在开发集发现程序类追问回归后被停止，结果保存在带 `_iteration1` 后缀的目录；该轮不计入正式前后对比。修复后已重新运行最终开发集与完整正式测试。
