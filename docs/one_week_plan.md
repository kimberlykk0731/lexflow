# 一周 MVP 计划（12 案例不变）

目标：**周五交一个能跑、能演、评测自洽的版本**，60 分左右；周末只修 bug、不做新功能。

> **当前进度**：12 案例 × 4 配置已用 DeepSeek 官方 API 跑完（约 0.17 元）；报告 PDF、8 页幻灯片、演示脚本、界面截图已生成。
> **只剩两件**：① 你 + 一名组员做 6–10 份盲审（约 2 小时）；② 录 5 分钟视频（可用 `report/demo_script.md`）。

## 0. 先冻结范围

- 只做 2 个案由：劳动争议解除、交通事故人身损害。
- 12 个脚本案例不变，gold 不改（除非发现法律错误）。
- 不做：新案由、RL、多 agent、类案检索、真实用户测试、DLawBench 全量。
- 主结果用**真实 API** 跑一遍；mock 只作工程对照。

## 1. 四个 owner（3 人就合并 B+C）

| Owner | 负责 | 交付物 |
|---|---|---|
| 你（法律/PM） | gold 复核、追问话术、盲审、报告法律部分、答辩 | 12 条 gold 核对表、6–10 份盲审、报告 §2/§4 |
| A（Agent/后端） | API 接入、真实模型跑通、修抽取/追问 bug、错误分析 | `eval_table_api.md`、错误案例表 |
| B（前端/演示） | Streamlit、截图、录屏、架构图 | 5 分钟视频、3 张图 |
| C（报告/数据） | 跑表、画图、method/eval 初稿、统稿排版 | 6 页 report、README 首屏 |

## 2. 按天排（周一到周五）

| 天 | 做什么 | 当天完成标准 |
|---|---|---|
| 周一 | 冻结范围；A 配 API；你核对 L01/L02/L07/T02 四条 gold；B 定录屏脚本 | `--llm api` 能跑通 L01、T01、L07 三个案例并出备忘录 |
| 周二 | A 修真实模型暴露的 bug；C 写 method；你补追问话术 | 12/12 案例不崩，生成第一版 API 结果表 |
| 周三 | 全量跑 3 个 seed；你 + 一名组员盲审 6–10 份；B 录 5 分钟初版 | 盲审表汇总；视频初版能看 |
| 周四 | C 写 eval/results；B 出架构图和主结果图；A 写错误分析 | 6 页 report 初稿 + 3 张图 |
| 周五 | 统稿、排练、打包；备份录屏 | 报告/视频/README 三件套齐，演示不超时 |
| 周末 | 只修 bug、改错别字 | 不再加功能 |

## 3. 能交的验收清单

- [ ] `PYTHONPATH=src python3 eval/run_evals.py --llm api` 跑完 12 案例，表格有真实数字。
- [ ] 三个 demo 场景不崩：模糊提问 → 追问；事实齐备 → 备忘录；更正事实 → 金额/时效变化。
- [ ] 报告六节齐全：动机、相关工作、方法、评测、结果、错误分析+局限。
- [ ] 5 分钟录屏 + 一个备用录屏（防现场网络/API 故障）。
- [ ] README 首屏能看懂：一句话、一张图、一条命令。
- [ ] 全文不出现“超过 Harvey/GPT”“新 benchmark”这类话。

## 4. 出问题时的砍法（按顺序）

1. 砍 B 的检索实验（embedding/rerank），保留 12 案例 + 录屏。
2. 砍 10 份盲审到 6 份，只报一致率，不报分歧细节。
3. 砍侵权场景的现场演示，只放录屏；劳动场景必须现场跑。
4. 报告从 8 页压到 5 页，保留主表 + 两张图。
5. 最后才砍“更正后重算”的现场演示——这是最值钱的一幕，尽量保。

## 5. “适当包装”清单

- **标题**：一句话说清“先问再答 + 事实改了会重算”，不要堆“多智能体/大模型”。
- **首屏**：一张截图（现在这张）+ 一句话 + 一条复现命令。
- **一张主结果表**：只放 `answer_first / gate_only / full / full_no_revision` 四行、四个指标（覆盖率、过早结论、引用核验、旧结论残留），其他进附录。
- **一张架构图**：intake → gate → research → memo → verify → revise，标出“事实修订”回边。
- **一段 90 秒录屏**：模糊提问 → 追问 → 备忘录 → 更正 → 金额变化。
- **报告最后一段**：“我们没测什么”——通用法律能力、真实用户、类案、金额精算。这一段比多吹一句更加分。
- **口径统一**：mock = 管线验证，API = 模型结果；一致性 ≠ 法律能力；controlled protocol ≠ benchmark。
