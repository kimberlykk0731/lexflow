## 人工审定的具体动作

1. 核对上述事实与适用假设，将每条gold映射到具体法名、条号、版本与事实。
2. 处理B18的社保时间歧义、B24的未知工资例外及B14的工伤工资基数；区分B17的条件咨询和已经成立的补偿请求。
3. 确认B03的请求选择与时效处理，补足B24、B32实际争点的审定范围。
4. 实际人类审查者在原七例表填写结论、理由、姓名，再更新对应案例状态。若修改题目或gold，发布新数据版本、更新哈希并重跑全部配置。
